# HomeAgent 远程设备关机（Remote Shutdown）设计方案

## 1. 背景与目标

在家庭与办公室局域网场景中，管理员或用户常需要对已接入 HomeAgent 的远程设备执行关机操作（如低功耗节能、离开办公室远程关机、或者配合 Wake-on-LAN 实现“按需开机，用毕关机”的完整电源生命周期管理）。

本功能旨在通过 HomeAgent 的 **SSE 实时下行控制平面**，安全、可靠、闭环地向指定在线 Agent 下发关机指令，并适配 macOS、Linux、OpenWrt 和 Windows 等全平台系统。

---

## 2. 架构与控制流

```
┌────────────────────────────────────────────────────────┐
│                   HomeAgent 控制端                     │
│  - Web 控制面板 UI (带二次确认弹窗)                     │
│  - RESTful API (POST /api/v1/devices/{id}/shutdown)    │
│  - Server CLI (homeagent-server shutdown <id|alias>)   │
└───────────────────────────┬────────────────────────────┘
                            │ (Bearer Token 鉴权)
                            ▼
┌────────────────────────────────────────────────────────┐
│                    HomeAgent Server                    │
│  1. 校验设备存在性与 SSE 在线状态                      │
│  2. 通过 Broker 单播下发 SSE 事件 (type: "shutdown")   │
│  3. 记录日志与审计追踪                                  │
└───────────────────────────┬────────────────────────────┘
                            │ SSE Stream (event: shutdown)
                            ▼
┌────────────────────────────────────────────────────────┐
│                   HomeAgent Agent 守护进程             │
│  1. 收到 shutdown 事件解析载荷                         │
│  2. 立即上报 ACK (module: "shutdown", status: "shutting_down") │
│  3. 异步短延迟 (1s) 后调用平台原生系统关机命令         │
└───────────────────────────┬────────────────────────────┘
                            │ 操作系统原生关机接口
                            ▼
     ┌──────────────────────┼──────────────────────┐
     │                      │                      │
┌────┴────────────┐  ┌──────┴──────────┐  ┌────────┴────────────┐
│ Linux / OpenWrt │  │      macOS      │  │       Windows       │
│ systemctl /     │  │ shutdown -h now │  │ shutdown.exe /s /t 1│
│ poweroff /      │  │ / osascript     │  │                     │
│ shutdown -h now │  │                 │  │                     │
└─────────────────┘  └─────────────────┘  └─────────────────────┘
```

## 3. 详细设计与协议规范

### 3.1 控制平面 SSE 协议

- **Event Type**: `shutdown`
- **Payload 格式** (`ShutdownPayload`):
  ```json
  {
    "reason": "web_ui_request",
    "delay_seconds": 1,
    "force": false
  }
  ```

### 3.2 客户端 ACK 上报

Agent 收到指令后，在实际关机前立即通过 HTTP POST 上报 ACK：
- **Endpoint**: `/api/v1/devices/{id}/ack`
- **Body**:
  ```json
  {
    "module": "shutdown",
    "status": "shutting_down",
    "applied_version": 0,
    "applied_hash": "",
    "error_message": "",
    "agent_version": "vX.Y.Z"
  }
  ```

### 3.3 跨平台关机执行策略 (`internal/daemon/shutdown.go`)

- **Linux & OpenWrt**：
  1. 优先尝试 `systemctl poweroff`（适用于 systemd 系统）；
  2. 若失败或无 systemd，尝试 `poweroff`（适用于 OpenWrt procd / busybox / Alpine）；
  3. 若均失败，尝试 `shutdown -h now`。
- **macOS (Darwin)**：
  1. 优先尝试 `shutdown -h now`（LaunchDaemons / root 身份生效）；
  2. 若权限不足（LaunchAgent 用户会话），尝试 AppleScript: `osascript -e 'tell application "System Events" to shut down'`。
- **Windows**：
  1. 调用 `shutdown.exe /s /t 1 /c "HomeAgent remote shutdown"`。

### 3.4 RESTful API 契约

- **路径**：`POST /api/v1/devices/{id}/shutdown`
- **鉴权**：`Authorization: Bearer <token>`
- **请求体（可选）**：
  ```json
  {
    "reason": "manual_request",
    "delay_seconds": 1,
    "force": false
  }
  ```
- **响应**：
  - `200 OK`: `{"device_id": "...", "status": "shutting_down", "listeners": 1}`
  - `400 Bad Request`: 设备离线未连接 SSE，或设备 ID 无效。
  - `404 Not Found`: 设备不存在。

### 3.5 Server CLI

```sh
# 按设备 ID 或别名关机
homeagent-server shutdown <device-id|alias> [--reason "..."] [--delay 1s] [--force]
```

### 3.6 Web UI 交互与防误触

- 在设备卡片操作区添加红色关机按钮 `⏻`（或包含关机文本）。
- 点击时弹出二次确认模态弹窗，提示：“确定要远程关闭设备【<hostname/alias>】吗？关机后可通过局域网唤醒（WOL）或物理电源开机。”
- 确认后发送 API 请求，并在按钮显示加载与成功提示。

## 4. 安全与可靠性考虑

1. **防网络中断丢包**：Agent 在触发关机命令前必须先完成 ACK HTTP 请求发送，并设置 1 秒的短延时，确保服务端和控制台能收到状态确认。
2. **防误触保护**：Web 控制台强制二次确认；API 强制 Token 认证。
3. **测试真实性与解耦**：关机执行器使用函数注入（`ShutdownExecutor`），避免在单元测试运行时意外导致宿主机被关闭。
