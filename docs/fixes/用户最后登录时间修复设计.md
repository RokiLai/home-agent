## 契约

`User.last_login_at` 是可空 UTC 时间戳。仅在用户名密码验证成功且会话成功创建时更新；认证失败、禁用账号和未建立会话不得更新它。`GET /api/v1/users` 必须返回该字段；无成功登录记录的存量与新建账号返回 `null`，前端显示“从未使用”。

该字段持久化在既有 `auth.json` 用户记录中。旧记录缺失字段时由 JSON 零值兼容为 `null`，不需要单独的数据迁移。Session 的 `last_seen_at` 不得作为该字段来源。

## 验证

测试覆盖成功登录更新时间、用户列表 API 返回时间戳、失败认证无更新以及重启后持久化保留。服务端组件版本随本次行为变更递增。
